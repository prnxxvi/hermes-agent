Privacy Policy - Hermes Agent

Last updated: 26 September 2026

Who uses this app

Hermes Agent is a personal, self-hosted tool. Its only user is its owner. It is not offered to or used by anyone else.

What data it accesses

When the owner signs in with Google, the app may access the owner's Gmail messages, Google Calendar events and Google Drive files, only within the permissions the owner approves.

How the data is used

The data is used only to perform tasks the owner asks for, such as reading and organising email, creating calendar events and managing files. It is not sold, not used for advertising and not shared with third parties, except the AI model provider the owner chooses to process requests.

Storage and security

OAuth tokens and any data are stored only on the owner's own computer. The owner can revoke access at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Hermes Agent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
